# Nama Aplikasi: Aplikasi Catatan Harian

## Deskripsi Singkat & Tujuan

Aplikasi Catatan Harian Sederhana adalah web mini yang memungkinkan pengguna menulis dan menyimpan catatan singkat secara langsung di browser.
Tujuannya untuk membantu user menyimpan catatan melalui web

### Fitur Utama:

- Menambahkan catatan baru ke halaman secara dinamis
- Menampilkan tangal dan waktu saat catatan dibuat
- Render DOM langsung tanpa framework

### Cara Pakai:

1. Tulis catatan
2. Klik tombol simpan catatan
3. Catatan yang kamu tulis akan muncul di bawahnya lengkap dengan waktu penyimpanan
4. Ulangi langkah yang sama untuk menambah catatan lain nya

## Struktur Folder dan Teknologi:

- HTML
- CSS
- Javascript
